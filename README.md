# QuickPoll — Create & Share Instant Polls

QuickPoll is a lightweight polling platform where users can create, share, and vote on polls with a clean and fast user experience. Built using the MERN stack with Firebase Authentication.

## 🚀 Features
- Create polls with multiple options  
- Explore publicly shared polls  
- Vote with or without login (creator controlled)  
- Secure authentication via Firebase  
- Clean and responsive UI with Tailwind CSS  
- Dashboard to manage polls you create  
- Auto-refreshing vote results  
- Route-level lazy loading for faster initial load

## 🔧 Setup Instructions

### 1. Repository
```
git clone https://github.com/cyphering101Raman/Quick-Poll-Frontend
git clone https://github.com/cyphering101Raman/Quick-Poll-Backend
```
---

## 🖥️ Backend Setup
```
git clone: https://github.com/cyphering101Raman/Quick-Poll-Backend
npm install
```

## Run backend:
```
npm run dev
```
---

## 🌐 Frontend Setup
```
git clone: https://github.com/cyphering101Raman/Quick-Poll-Frontend
npm install
```
---

## Run frontend:
```
npm run dev
```
---

## 🔁 How It Works
- User creates a poll
- Poll data stored in MongoDB
- Other users can vote and view results
- Creator can manage polls through the dashboard
- Votes update dynamically when requested
